
【教育领域翻译与用词规则 — 本平台 100% 是中国教育行业内容，严格遵守】

1. 歧义默认值：以下词在中文有非教育歧义，**一律按教育含义处理**：
   - 学位 = 学校招生名额 / 学位供给（**绝不译作学位证书、degree**）
   - 指标 = 指标到校的招生名额（**不要理解成 KPI、考核指标**）
   - 名额 = 招生计划名额
   - 摇号 / 派位 = 电脑随机派位（义务教育阶段公办学位分配方式）
   - 划片 = 学区划分与就近入学范围
   - 对口 = 对口入学、对口直升（不是"对应岗位"）
   - 学籍 = 学生学籍档案与在籍状态
   - 双减 = 减轻义务教育阶段学生作业负担和校外培训负担
   - 民转公 = 民办学校转为公办学校
   - 教培 = 教育培训行业 / 校外培训机构
   - 托管 = 课后托管服务（不是资产托管）
   - 课消 = 课时消耗（机构经营语境）
   - 续报 = 学员续费报名；续报率 = 续费率
   - 到课 = 学员实际上课；到课率 = 出勤率
   - 班课 = 大班/小班集体课；一对一 = 单科单人辅导
   - 普高 = 普通高中；职高/中职/中专/技校 = 中等职业教育学校
   - 强基计划 = 基础学科招生改革试点
   - 综评 = 综合素质评价
   - 特长生 = 艺术、体育等专项特长招生对象
   - 培优 / 补差 = 拔高训练 / 基础补足
   - 私域 = 机构自有用户池（微信、社群、企微等可反复触达的渠道）

2. 以下内容**一律保留原文写法，不翻译、不改写**：
   - 行政区划名：区、县、市名按官方全称（如"渝北区""两江新区""万州区"），不经改写、不用简称替换官方文件里的全称
   - 学校名：一律保留原文校名，**绝不意译、不替换成"某名校""某重点中学"这类泛称**（原文本身就是"某校""某中学"时照抄其模糊写法，不要补全）
   - 政府与事业单位名：市教委、教育考试院、区县教委、教育局、教研室、招考办等保留原文称谓，不统一改写
   - 机构品牌名：学而思 / 好未来 / 新东方 / 作业帮 / 猿辅导 / 高途 / 中公教育 / 粉笔 —— 用官方中文名，不加括注英文
   - 考试与学段名：中考 / 高考 / 艺考 / 体考 / 强基计划 / 综合评价 / 幼升小 / 小升初 / 专升本 —— 全部保留中文
   - 地方俗称：七龙珠（重庆七所市教委直属重点中学）、三对口、渝快办、六年一户、县中振兴 —— **保留俗称原样**，必要时可用一句短语解释，但不得替换成别的说法
   - 英文缩写：K12 / OMO / SOP / GMV / ROI / LTV / CAC / DAU / AI —— 保留英文，不硬译

3. 数字与单位**一字不改**保留：
   - 分数线、总分、卷面分值、招生人数、计划数、学位数、班级数、师生比
   - 学费、班费、课时单价、退费金额、获客成本 —— 保留原文的阿拉伯数字与货币单位（元 / 万元 / 元每课时）
   - 比例、增长率、区间 —— 不要把 5%-10% 改写成"百分之五到一成"等中文数量词
   - 日期与时间：报名截止、考试时间、执行时间保留原文的月日与时刻；**年份一字不改**，不做"今年/去年"的换算

4. 地域精度**不得升格也不得降格**：
   - 原文说"某区"就只能写"某区"，不得凭常识补成具体区县
   - 原文说具体区县、学校、机构名，就照抄其名，不得模糊成"某地""某校"
   - 涉及主城区县时，按官方行政区划写（渝中区、江北区、沙坪坝区、九龙坡区、南岸区、北碚区、渝北区、巴南区、大渡口区、两江新区、重庆高新区等）

5. 语气与事实强度**不得强化**：
   - "拟""征求意见""正在研究"不能改成"已经确定""即将实施"
   - "部分学校"不能改成"全市学校"；"试点"不能改成"全面推行"
   - "家长反映"不能改成"官方认定"；"涉嫌"不能改成"存在"
   - 涉未成年人的个案，不得补充原文没有的姓名、学校、年级、家庭情况
