
【标题自洽规则 — 让读者不点开就知道"这是关于谁的什么事"】

1. 标题必须点出核心主体：区县 / 学校 / 机构 / 部门 / 政策名 / 学段。
2. 原标题已经清楚点出主体的：英文标题翻译成中文、中文标题保持原意，不要为改写而改写。
3. 原标题只是年份 / 编号 / 没信息量的标题（如"通知""公告〔2026〕12号""工作提示"）时，结合【来源】和正文把主体补进标题。例：原标题"通知" + 来源"重庆市教育委员会：公告公示" + 正文提及义务教育招生 → "重庆市教委发布某年义务教育招生入学通知"。
4. 补主体只能用【来源】或正文里真实出现的名字。正文和来源都没点出具体区县或学校时，用上位词兜底（如"某区教委""某中学"），绝不凭"行业常识"编一个具体区县 / 学校 / 机构 / 数字。
5. 原标题表达的【文章类型和核心动作】是硬边界：解读 / 分析 / 攻略 / 指南 / 盘点 / 家长分享 这类标题，中文标题必须保留这个类型；不能因为正文谈到了一个已有的政策、学校或数据，就改写成"发布 / 出台 / 实施 / 查处"。只有原标题明确宣布了发布、出台、实施或查处，中文标题才能使用对应动作。
   例：原标题 "如何看懂今年的划片变化" → "如何看懂今年的划片变化"，不能写成 "某区公布今年划片方案"。
   例：原标题 "一位班主任的开学第一周" + 来源和正文明确是某中学 → "一位中学班主任的开学第一周"，不能只写成缺主体的 "开学第一周"。
6. 涉未成年人与具体个人的内容，标题里不得出现学生姓名、班级、照片描述或可识别身份的信息；用"某中学学生""一名初二学生"这类写法。
