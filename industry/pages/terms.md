页首说明：

> 本站聚合公开信源，用模型生成中文摘要与精选，原文版权归各来源所有。网站、RSS、公开 API 与 MCP 均可匿名使用。

## 1. 内容与版权

本站展示的标题、摘要和推荐理由由模型根据公开来源生成，可能有误，重要信息请以原文为准。原文版权归各来源所有；站内只在来源允许时展示全文，其余只展示摘要和原文链接。

## 2. 教育信息的特别说明

本站不是官方发布渠道，也不提供升学咨询与报考建议。

- **政策与招生类信息**（划片范围、报名条件、招生计划、录取规则、收费标准等）一律以教育行政部门、教育考试院与学校发布的原文为准。本站摘要可能存在滞后、遗漏或转述偏差，报名与填志愿前请核对原文。
- **涉及时效的节点**（报名起止、审核时间、考试安排、成绩与分数线公布）请以官方渠道的最新通知为准。
- **一线声音类内容**为从业者个人观点与经验自述，不代表本站立场，也不构成事实认定。
- 涉及未成年人的内容，本站不展示其姓名、班级、成绩排名与可识别身份的信息；如发现遗漏，请通过反馈页告知。

## 3. 来源方的更正与下架

如果你是来源方（教委、学校、教育机构或媒体），希望更正、下架或调整展示方式，请通过反馈页联系我们，我们会尽快处理。

## 4. 使用本站的数据

请写明你允许的用途（例如个人阅读、组织内部使用），以及需要事先取得你同意的用途（例如商业产品、公开转载、批量再分发）。

## 5. 接口与频率

RSS、公开 API 和 MCP 为匿名只读接口。请按响应中的缓存时间轮询，遇到 429 请遵守 Retry-After，不要并发重试。

## 6. 免责

本站按“现状”提供，不保证内容完整、准确和持续可用。因使用本站信息作出升学、报考或经营决策而产生的后果，由使用者自行承担。
